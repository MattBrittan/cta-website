# CTA location map

The compact green version is used in the website hero, above the photo credit. The larger original remains a preview.

- SVG: `cta-nz-location-preview.svg`
- PNG: `cta-nz-location-preview.png`
- Approximate project locator: Castle Hill Village, 171.7147° E, 43.2089° S; not a project boundary or trap location.
- Outline: Natural Earth 1:50m countries (public-domain cartographic data), main North, South and Stewart islands and nearby islands. Offshore island groups are outside the map extent.
- Projection: local equirectangular, standard parallel 41° S.
- Project context: https://www.castlehill.nz/craigieburn-trapping-alliance/
- Geographic data: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/

The CTA describes its work as centred on the Castle Hill Basin, with a wider project area from the Cass River to Lake Lyndon. The pin is a general locator only.

## Compact outline version

`cta-nz-location-compact.svg` and `.png` show a green New Zealand silhouette and approximate location marker, on a transparent background. Intended display size: 250 × 350 pixels. The website uses a copy at `public/cta-nz-location.svg`, displayed smaller to fit the hero. Uses the same geographic data and locator as the original preview.
